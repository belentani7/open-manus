Local first · Windows 11

Tu taller de agentes.

Prepara OpenManus con Ollama y crea proyectos independientes a partir de plantillas locales. Sin exponer servicios ni ejecutar comandos desde esta web.

Configurar proyectoPreparar entorno
PowerShell / ejemplo
PS > .\scripts\check-system.ps1
PS > .\scripts\setup-openmanus.ps1
PS > ollama pull qwen2.5:7b
PS > .\scripts\start-cli.ps1

Los comandos deben ejecutarse en tu equipo desde el repositorio clonado. No se muestra un estado remoto inventado.

01 / Project factory

Configura tu próximo proyecto.

Generador de comandos para la fábrica PowerShell existente. Previsualiza primero con WhatIf; no se sobrescriben directorios con contenido.

Destino: carpeta Projects de tu usuario de Windows.

Comando generado:

.\scripts\New-Project.ps1 -ProjectName "MyAgent" -Template general -Workspace "$HOME\Projects" -WhatIf

02 / Setup

Del repositorio al entorno local.

01

Requisitos

Windows 11, Python 3.11+, Git y Ollama. Ejecuta check-system.ps1 para comprobar el entorno real.

02

Preparación

setup-openmanus.ps1 configura el entorno virtual y conserva la configuración existente.

03

Verificación

python -m unittest discover -s tests -v

Ejecuta las pruebas antes de actualizar el entorno.
